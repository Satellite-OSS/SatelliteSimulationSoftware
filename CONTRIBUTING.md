# Contributing

Thank you for improving the SatelliteSimulationSoftware directory.

## Add or update an entry

1. Place the entry in one simulation domain and state a concise, evidence-backed scope.
2. Link to the project's official repository, website, or documentation. Do not link to a search result, fork, mirror, or a URL that has not been checked.
3. State the source article, paper, documentation page, or release note that supports the entry.
4. Add the retrieval date when a source is time-sensitive.
5. Do not copy extended third-party descriptions. Use short paraphrases and retain a direct citation.

## Source-status labels

- `Source-listed`: the cited source explicitly lists the project in a relevant category. This is not an endorsement or a claim that every release remains maintained.
- `Primary link verified`: the catalog entry includes an official repository, maintained project page, or official documentation link that has been checked by a contributor.

## Pull requests

Keep each pull request focused. For a new project, include its name, category, primary URL, source URL, and a one-sentence explanation of why it belongs in that category. Please preserve the English and Simplified Chinese README parity.
